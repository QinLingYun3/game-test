## Why

单人模式目前缺乏时间压力机制，玩家可以无限思考，导致游戏节奏单调、缺乏紧张感。增加倒计时功能可以提升游戏的挑战性和趣味性，让玩家在有限时间内做出决策，增强游戏的策略深度和重复可玩性。

## What Changes

- 在单人模式游戏界面新增倒计时卡片，显示剩余时间
- 倒计时规则：每关总时间 = tile 数量 × 1.5 秒
- 游戏结束时（时间到 0）自动保存分数并显示结算面板
- combo 奖励机制：每出一个 combo，时间增加 2 秒
- 跨关卡时间转化：通关时剩余时间转化为分数（1 秒 = 100 分，根据难度系数：容易 50 分/秒、中等 100 分/秒、困难 200 分/秒），下一关倒计时重置
- 道具效果调整：
  - 速消：额外减少 4 秒倒计时（更新道具说明）
  - 洗牌：洗牌期间倒计时暂停（更新道具说明）
- 倒计时 UI 视觉效果：
  - 初始亮橙色，随时间减少向鲜红色渐变并显示进度条
  - 剩余 10 秒时数字闪烁并跳动

## Capabilities

### New Capabilities
- `countdown-timer`: 单人模式倒计时系统，包括时间计算、combo 奖励、跨关卡继承、道具交互、时间到 0 的游戏结束逻辑
- `countdown-ui`: 倒计时卡片 UI，包括样式、颜色渐变、进度条、闪烁跳动动画

## Impact

- 单人模式游戏逻辑层（时间计算、combo 监听、关卡切换）
- 游戏结束流程（时间到 0 触发结算）
- 道具系统（速消、洗牌的倒计时交互）
- UI 层（新增倒计时卡片组件，更新道具说明文本）
