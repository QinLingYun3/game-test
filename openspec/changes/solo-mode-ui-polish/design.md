## Context

单人模式已上线，包含倒计时、combo、关卡切换等核心机制。本次变更是对已有功能的 UI/UX 微调，不涉及游戏逻辑变更。

## Goals / Non-Goals

**Goals:**
- 结算页面提供返回首页的快捷入口
- 优化首页文案，降低用户理解成本
- 简化首页关卡选择区域的视觉元素

**Non-Goals:**
- 不修改游戏核心逻辑
- 不新增游戏机制
- 不影响多人对战模式

## Decisions

### 1. 返回首页按钮使用 secondary-btn 样式
**决策**：与再来一局的 primary-btn 形成视觉层级区分。
**理由**：再来一局是主操作，返回首页是次操作，样式区分符合用户预期。

### 2. 默认改为闯关
**决策**：将 difficulty.default 的翻译从默认/Default/Par defaut改为闯关/Campaign/Campagne。
**理由**：默认没有传达出按顺序通关所有关卡的含义，闯关更直观。

### 3. 去掉选择关卡文字标签
**决策**：直接移除 mode-label 文字标签，仅保留下拉框。
**理由**：下拉框本身已能表达功能，文字标签增加视觉冗余。

## Risks / Trade-offs

- **[Risk]** 去掉选择关卡文字后，新用户可能不理解下拉框的用途
  → **Mitigation**：下拉框的第一个选项是全部关卡，且选项内容包含关卡名称和层数，足够自解释
